# Notice

## CFB 27 Automatic Force Win

The `SeasonGame.ForceWin` write path, its protections (skip played / already
forced / postseason rows) and the before/after snapshot validation are ported
from *CFB 27 Automatic Force Win* v0.5.0 by ArtVsTheWorld ("Ace"), which is
distributed under the MIT license. The ratings-based decision logic of that
tool is not used here; this project replaces it with real-life results.

## madden-franchise

Save file reading and writing uses
[`madden-franchise`](https://github.com/bep713/madden-franchise)
(MIT, by its contributors), installed from npm.
